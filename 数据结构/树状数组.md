# 树状数组

## 快速计算lowbit(i)代码模版

```cpp
int lowbit(int x){
    return x & -x;
}
```

## 单值修改代码模版

```cpp
void update(int x,int y){//a[x]增加y
    while(x <= n){
        c[x] += y;
        x += lowbit(x);    
    }
}
```

## 构建树状数组
```cpp
for(int i=1;i<=n;i++){
        cin >> a[i];
        update(i,a[i]);
 }
```
