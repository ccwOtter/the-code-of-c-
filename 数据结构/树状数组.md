# 树状数组

## 快速计算lowbit(i)代码模版

```cpp
int lowbit(int x){
    return x & -x;
}
```

## 单值修改代码模版

```cpp
void update(int x,int y){//a[x]增加y
    while(x <= n){
        c[x] += y;
        x += lowbit(x);    
    }
}
```

## 构建树状数组
```cpp
for(int i=1;i<=n;i++){
        cin >> a[i];
        update(i,a[i]);
 }
```

## 求前缀和
```cpp
int s(int x){
        int ans = 0;
        while(x > 0){
            ans += c[x];
            x -= lowbit(x);
        }
        return ans;
}
```

## 二维单值修改
```cpp
void update(int x,int y,int k){ 
        for(int i = x;i <= n;i += lowbit(i)) 
            for(int j = y;j <= m;j += lowbit(j))
                c[i][j] += k;
}
```
## 二维构建
```cpp
for(int i = 1;i <= n;i++){
        for(int j = 1;j <= m;j++){
            cin >> a[i][j];
            update(i,j,a[i][j]);    
        }
}
```
## 前缀和
```cpp
int s(int x,int y){//求以(1,1),(x,y)分别为左上顶点,右下顶点的矩形区域内的和
        int ans = 0; 
        for(int i = x;i > 0;i -= lowbit(i)) 
            for(int j = y;j > 0;j -= lowbit(j))
                ans += c[i][j]; 
        return ans;
}
```
