# 二叉堆
## 插入(上浮)
```cpp
void heap_push(int d){
    a[++n]=d;
    for(int i=n;i!=1;i/=2){
        if(a[i]>a[i/2])
            swap(a[i],a[i/2]);
        else break;
    }
}

```
## 下沉
```cpp
void heap_shiftdown(int i){
    int MAX;
    if(2*i>n) return;
    MAX=2*i;
    if(2*i+1<=n && a[2*i]<a[2*i+1]) MAX=2*i+1;
    if(a[i]<a[MAX]){
        swap(a[i],a[MAX]);
        heap_shiftdown(MAX);
    }
}
```
## 删堆顶
```cpp
void heap_pop(){
    swap(a[1],a[n]);
    n--;
    heap_shiftdown(1);
}
```
