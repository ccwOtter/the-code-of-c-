# 一、字典树

## 1、插入

```cpp
void insert(string str) { // 插入字符串 
    int p = 1;
    for (int i = 0; i < str.size(); i++) {
        int ch = str[i]-'a';
        if (trie[p][ch] == 0) trie[p][ch]=++tot;
        p = trie[p][ch];
    }
    f[p]++;
}
```

## 2、查询

```cpp
int search(string str) {
    int p = 1;
    for (int i = 0; i <  str.size(); i++) {
        int ch = str[i]-'a';
        if (trie[p][ch] == 0) return 0;
        p = trie[p][ch];
    }
    return f[p];
}
```
