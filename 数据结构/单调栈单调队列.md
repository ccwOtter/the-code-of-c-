# 单调栈
```cpp
// 正序遍历
    for (int i = 1; i <= n; i++) {
        // 弹出所有不大于 a[i] 的元素
        while (!st.empty() && a[st.top()] <= a[i]) {
            st.pop();
        }
        // 如果栈不为空，栈顶就是左边第一个大于 a[i] 的元素
        if (!st.empty()) {
            ans[i] = st.top();
        } 
        // 当前元素入栈
        st.push(i);
    }

```
