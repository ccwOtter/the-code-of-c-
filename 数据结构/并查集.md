# 并查集（Union-Find）

并查集是一种树型的数据结构，用于处理不相交集合（Disjoint Sets）的合并及查询问题。

## 1、初始化

```cpp
for(int i=1; i<=n; i++){
    fa[i] = i;
}
```

## 2、查询

### （1）查询元素 x 所在树对应的根结点（含路径压缩）

**写法 1：**

```cpp
int find(int x){
    if(fa[x] != x) fa[x] = find(fa[x]);
    return fa[x];
}
```

**写法 2：**

```cpp
int find(int x){
    if(fa[x] == x) return x;
    return fa[x] = find(fa[x]);
}
```

**写法 3：**

```cpp
int find(int x){
    return fa[x] == x ? x : fa[x] = find(fa[x]);
}
```

### （2）判断两个结点是否在同一棵树上

```cpp
bool same(int x, int y){
    return find(x) == find(y);
}
```

## 3、合并

```cpp
void merge(int x, int y){
    int fx = find(x);
    int fy = find(y);
    fa[fx] = fy;  // fa[fy] = fx; 也可
}
```
