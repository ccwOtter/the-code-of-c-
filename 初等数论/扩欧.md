# 扩欧
扩展欧几里得算法，返回 gcd(a,b)，并求 ax+by=gcd(a,b) 的一组特解
## 扩欧算法模版
```cpp
// 扩展欧几里得算法，返回 gcd(a,b)，并求 ax+by=gcd(a,b) 的一组特解
ll exgcd(ll a, ll b, ll &x, ll &y) {
    if (b == 0) {
        x = 1;
        y = 0;
        return a;
    }
    ll nx, ny;
    ll g = exgcd(b, a % b, nx, ny);
    x = ny;
    y = nx - (a / b) * ny;
    return g;
}

```
## 裴蜀定理
设 a 和 b 是两个不全为零的整数，d 是 a 和 b 的最大公约数。

第一，一定存在两个整数 x 和 y，使得 a 乘以 x 加上 b 乘以 y 等于 d。

第二，对于任意整数 c，方程 a 乘以 x 加上 b 乘以 y 等于 c 有整数解，当且仅当 d 能整除 c

```cpp
#include <bits/stdc++.h>
using namespace std;
int a[25];
int gcd(int a,int b){
    return b==0 ? a:gcd(b,a%b);
}
int main() {
    int n;
    cin >> n;
    for (int i = 1; i <= n; i++) {
        cin >> a[i];
    }
    int g = 0;
    for (int i = 1; i <= n; i++) {
        g = gcd(g, abs(a[i]));
    }
    cout << g;
    return 0;
}
```
