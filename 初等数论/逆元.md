## 扩欧求
```cpp
// 扩展欧几里得算法，返回 gcd(a,b) 并求出 ax+by=gcd(a,b) 的一组解
ll exgcd(ll a, ll b, ll &x, ll &y) {
    if (b == 0) {
        x = 1;
        y = 0;
        return a;
    }
    ll nx, ny;
    ll g = exgcd(b, a % b, nx, ny);
    x = ny;
    y = nx - (a / b) * ny;
    return g;
}
// 求a关于p的逆元
exgcd(a, p, x, y);
 // 确保结果在 [0, p-1] 范围内
 int inv = (x % p + p) % p;
```

## 费马小定理
设 p 是一个素数，a 是任意整数  a^(p-1) ≡ 1 (mod p)

如果 a 不能被 p 整除，那么 a 的 p 减 1 次方除以 p 的余数等于 1。
```
a^(-1) ≡ a^(p-2) (mod p) !!!!!!!!!!!!!!
```
## 递推逆元
模数 p 必须是素数。

通常我们要求 1 到 n 的逆元，且 n < p。

inv[1] = 1

对于 i ≥ 2：

inv[i] = ( p - p/i ) × inv[ p % i ] % p

```
公式推导（简略版）
设 p = k × i + r，其中 k = p / i（整数除法），r = p % i（余数）。
因为 r < i，所以 inv[r] 已经提前被算出来了。

对 p = k × i + r 两边取模 p，得到：
k × i + r ≡ 0 (mod p)

两边同时乘以 inv[i] × inv[r]：
k × inv[r] + inv[i] ≡ 0 (mod p)

移项得到：
inv[i] ≡ -k × inv[r] (mod p)

因为 k = p / i，r = p % i，所以：
inv[i] = ( p - p/i ) × inv[ p % i ] % p

这里的 p - p/i 是为了保证结果为正数。
```
