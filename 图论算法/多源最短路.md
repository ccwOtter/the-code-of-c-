#拓展模版：处理传递闭包问题

for(int k=1;k<=n;k++){
      for(int i=1;i<=n;i++){
	  for(int j=1;j<=n;j++){
                  d[i][j] = d[i][j] || d[i][k] && d[k][j];
            }
      }
}
