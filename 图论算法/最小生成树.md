# 最小生成树

## Kruscal（克鲁斯卡尔）算法
通过每次添加权值最小且不构成环的边来求解，是一种贪心算法。其步骤为：设 E' 为已选边的集合

1、E' 为空集，将E中的所有边按照权值做升序排序，记该序列为L；

2、依次选择L中的边，如果当前边与E' 中的边不构成环，即当前边的两个顶点不在已选边所构成森林的同一棵树中，则将其加入到E' 中。

3、E' 中的边达到 n-1 时，停止寻找，算法终止，此时得到的 T = (V, E') 即为最小生成树。
```cpp
struct edge{
    int u;
    int v;
    int w;
}e[m];//m为边的数量
bool cmp(edge a,edge b){
    return a.w<b.w;
}
int find(int x){
    if(fa[x]!=x) fa[x]=find(fa[x]);
    return fa[x];
}
int kruskal(){
    sort(e+1,e+m+1,cmp);
    for(int i=1;i<=n;i++) fa[i]=i;
    for(int i=1;i<=m;i++){
        int x=e[i].u,y=e[i].v;
        int fx=find(x),fy=find(y);
        if(fx!=fy){            
            fa[fx]=fy;
            ans+=e[i].w;
            cnt++; 
        }
        if(cnt==n-1) break;
    }
    return cnt==n-1?ans:-1;    
}
```
## Prim算法
通过每次添加距离当前的树最近的树外顶点来实现，本质上也是一种贪心算法。其步骤为：设 E' 为已选边的集合，V' 为已选顶点的集合

1、任意选择某个顶点 vi，将其加入到 V' 中；

2、在 V' 外顶点中，选取到 V' 的距离最小的顶点 u，将连接 u 及其在 V' 中最近顶点 v 的边（u, v）加入到集合 E' 中，再将 u 加入到 V' 中；

3、更新 V' 外顶点到 V' 的距离；

4、重复步骤（2）和（3），直到 V' 中包含全部 n 个顶点为止
```cpp
int prim(){
    int ans=0,cnt=0;
    memset(d,0x3f,sizeof(d));
    d[1]=0;
    for(int i=1;i<=n;i++){
        int mind=0x3f3f3f3f,u=0;
        for(int j=1;j<=n;j++){
            if(!vis[j]&&d[j]<mind){
                mind=d[j];
                u=j;
            }
        }
        if(!u) break;
        vis[u]=1;
        ans+=mind;
        cnt++;
        for(int v=1;v<=n;v++){
            if(!vis[v]) d[v]=min(d[v],e[u][v]);
        }
    }
    return cnt==n?ans:-1;
}
```
