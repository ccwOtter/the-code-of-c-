# 树的重心
概念：如果在树中选择某个结点并删除，这棵树将分为若干棵子树，统计各个子树结点数并记录最大值，此最大值称为该结点的重量。重量最小的结点称为整个树的重心。

性质：
以树的重心为根时，所有子树的大小都不超过整棵树大小的一半。（等价定义1）

树中所有点到某个点的距离和中，到重心的距离和是最小的，如果有两个重心，他们的距离和一样。（等价定义2）

一棵树最多有两个重心，且相邻。

把两棵树通过一条边相连，新的树的重心在原来两棵树重心的连线上。

一棵树添加或者删除一个叶子结点，树的重心最多只移动一条边的位置。
## 重心
```cpp
vector<int> e[N],centroids;
int treesize[N],weight[N];
void dfs(int u,int fa){
    treesize[u]=1;
    weight[u]=0;
    for(int i=0;i<e[u].size();i++){
        int v=e[u][i];
        if(v!=fa){
            dfs(v,u);
            treesize[u]+=treesize[v];
            weight[u]=max(weight[u],treesize[v]);
        }
    }
    weight[u]=max(weight[u],n-treesize[u]);
    if(weight[u]<=n/2) centroids.push_back(u);
}
```
## 直径
```cpp
int bfs(int s){
    memset(vis,0,sizeof(vis));
    memset(dis,0,sizeof(dis));
    q.push(s);vis[s]=1;
    int maxdis=0,index=0;
    while(q.size()){
        int u=q.front();q.pop();
        for(int i=0;i<e[u].size();i++){
            int v=e[u][i];
            if(!vis[v]){
                q.push(v);
                vis[v]=1;
                dis[v]=dis[u]+1;
                if(dis[v]>maxdis){
                    maxdis=dis[v];
                    index=v;
                }
            }
        }
    }
    return index;
}
int diameter(){
    int index=bfs(1);
    index=bfs(index);
    return dis[index];
}
```
