
# 欧拉图
无向图：有0或2个奇点的连通图


有向图：有0个或2个奇点的弱连通图，若0个奇点，每个点入度=出度，若2个奇点，一个奇点入度=出度+1，另一个出度=入度+1

## 判断无向图连通性
```cpp
vector<int> e[N];//使用vector数组存储图，N为结点数量
void dfs(int u){
    if(vis[u]) return;
    vis[u]=1;
    for(int i=0;i<e[u].size();i++){
        int v=e[u][i];
        dfs(v);
    }    
}
```

## 求解欧拉路径-：Hierholzer算法模版（空间+时间优化）

### 无向图

```cpp
vector<pair<int,int>> e[N];
int vis[M];
int del[N];
stack<int> stk;
void dfs(int u){
    while(del[u]<e[u].size()){
        int v=e[u][del[u]].first;
        int id=e[u][del[u]].second;
        del[u]++;
        if(vis[id]) continue;
        vis[id]=1;
        dfs(v);
    }
    stk.push(u);
}

```
### 有向图

```cpp
vector<int> e[N];
int del[N];
stack<int> stk;
void dfs(int u){
    while(del[u]<e[u].size()){
        int v=e[u][del[u]];
        del[u]++;
        dfs(v);
    }
    stk.push(u);
}

```
