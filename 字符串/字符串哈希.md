# 字符串哈希
设置质数base，mod
对于字符串s，哈希为s[0]8base^0+s[1]*base^1+...+s[leng]*base^leng
## 单哈希
```cpp
#define base 131
#define MOD 1000000007
set<ll> st;
ll gethash(string s){
	ll ans = 0;
	for (int i = 0; i < s.size(); i++)
		ans = (ans * base + s[i]) % MOD;//单哈希
	return ans;
}
```
## 自然溢出
```cpp
#define ull unsigned long long
#define base 131
set<ull> st;
ull gethash(string s){
    ull ans = 0;
    for (int i = 0; i < s.size(); i++)
        ans = ans * base + s[i];  // 自然溢出，无需取模
    return ans;
}
```
## 双hash
```cpp
#define base1 131
#define base2 13331
#define MOD1 1000000007
#define MOD2 1000000009
set<pair<ll, ll>> st;  // 存储两个哈希值的pair
pair<ll, ll> gethash(string s){
	ll h1 = 0, h2 = 0;
	for (int i = 0; i < s.size(); i++){
		h1 = (h1 * base1 + s[i]) % MOD1;
		h2 = (h2 * base2 + s[i]) % MOD2;
	}
	return {h1, h2};
}
```
## 求子串数量
```cpp
#include <bits/stdc++.h>
using namespace std;
// 使用无符号长整型自然溢出取模（等价于模 2^64）
#define ull unsigned long long
#define base 131
ull hasha[1000005],bpow[1000005],hashb;
int main() {
    string a, b;
    getline(cin, a);  // 读取可能包含空格的字符串 a
    getline(cin, b);  // 读取可能包含空格的字符串 b
    int n = a.length();
    int m = b.length();
    if (m > n) {
        cout << 0 << endl;
        return 0;
    }
    bpow[0] = 1;
    for (int i = 1; i <= n; i++) {
        hasha[i] = hasha[i - 1] * base + a[i - 1];//hasha[i]表示前i个字符组成的前缀字符串的哈希值
        bpow[i] = bpow[i - 1] * base;//base[i]=base^i
    }
    for (int i = 0; i < m; i++) {
        hashb = hashb * base + b[i];
    }
    int cnt = 0;
    for (int i = 0; i <= n - m; i++) {
        // 计算 a[i~i+m-1] 的哈希值
        ull subhash = hasha[i + m] - hasha[i] * bpow[m];
        if (subhash == hashb) {
            cnt++;
        }
    }
    cout << cnt << endl;
    return 0;
}
```
