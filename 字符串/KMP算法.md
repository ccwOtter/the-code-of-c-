# KMP
模式串匹配问题：给出一个文本串和模式串，查询模式串在文本串中出现的次数或位置等的问题。

KMP算法针对模式串构建特定的数组，在匹配失败时用来减少后续匹配中的无效或不必要的比较，从而可以在线性时间复杂度内解决此类问题。
## 部分匹配表（PMT）：next数组
设文本串是 S，长度为 n；模式串为 T，长度为 m。

定义 T[i~r] 表示 T 字符串中第 i 个到第 r 个字符组成的子串。

KMP算法对于模式串 T 构建的特定数组，称为部分匹配表，记为数组 next：

next[i] = j：代表前 i 个字符组成的字符串中，前缀字符串和后缀字符串相等时的最长长度，即
T[1 ~ j] = T[i-j+1 ~ i]，j 为小于 i 的数中满足该条件的最大值。
### next数组的计算及代码实现
next数组按照下标的递增顺序依次进行计算，计算过程如下：

设 j = next[i-1]，若 T[j+1] = T[i]，则 next[i] = j+1；

若不相等，j 需要变成小于 j 的数组中，满足 T[1~j] = T[i-j~i-1] 的最大值，即 j = next[j]；此时若 T[j+1] = T[i]，则 next[i] = j+1；

若不相等，则重复步骤2，直到 j = 0 为止。
```cpp
void PMT(){
    nxt[1] = 0;
    for(int i = 2, j = 0; i <= m; i++){
        while(j && t[j+1] != t[i]) j = nxt[j];
        if(t[j+1] == t[i]) j++;
        nxt[i] = j;
    }
}
```
## KMP匹配与实现
遍历主串的每个字符，如果匹配则模式串指针前进，如果不匹配则利用next数组回退模式串指针，当模式串指针到达末尾时找到一个匹配并计数，然后回退继续寻找下一个匹配
```cpp
void kmp(){
    cnt = 0;
    PMT();
    for(int i = 1, j = 0; i <= n; i++){
        while(j && t[j+1] != s[i]){
            j = nxt[j];
        }
        if(t[j+1] == s[i])
            j++;
        if(j == m){
            cnt++;
            j = nxt[j];
        }
    }
}
```
